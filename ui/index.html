★ Key feature

Citation numbering

[n] in the response matches your revised manuscript — no manual renumbering.

Paper Smith [14] Lee [22]
Response Cite Smith → [14] New ref → [23]

Setup

  • Copy cite order from .bbl → rr_paper_cite_order.tex
  • \RRApplyPaperCiteOrder in main.tex
  • Each section ends with \RRSectionBibliography
Bonus

Paste old and new .tex — latexdiff generates the marked-up manuscript automatically.
